Itinerarium is an app for planning trips.

It has a trips list page, where trips show as tiles.

When selecting a trip, the main view is a timeline. It should automatically centre to the current time, or as close to it as possible in the events, and is scrollable up or down. It is depicted as a vertical line of tasteful thickness, with rounded blocks on it, which are the events.

The trip is composed of events. Events have places, times, documents (files), and freeform notes which can include links. Documents should not be uploaded to a database but kept locally on the user's device, unless they have entered a Google Drive service account in Settings.

Events have an order which is derived from their times or just their place on the timeline. So if you set a time for an event, and then change it, the event should move to after any other noted time.

The timeline mode is intended to be used during the trip to see what you should be doing now, so you can wake up, pull it up, and see.

From the timeline mode, you can press edit. Edit expands the timeline a bit and surfaces an "edit" link on all events, and + buttons between them, allowing you to add more events. 

You should be able to share a public link to your trip, allowing others to view it without auth.
